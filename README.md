## Free hosting with GitHub Pages
1. Sign in at https://github.com/ and create a **public** repository named `sunmark-automations-website`.
2. Upload `index.html` to the repository root and commit the changes.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose branch `main` and folder `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site. It will show a temporary `github.io` address.
6. Under **Settings → Pages → Custom domain**, enter `sunmarkautomations.com` and save.
7. At the registrar where you purchased the domain, open DNS settings and add the records recommended by GitHub Pages for your domain. Use GitHub's current guide for the exact records.
8. Do not delete existing MX or TXT records used for email.
9. If you also want `www.sunmarkautomations.com`, follow GitHub's guide to configure both root and `www` names.
10. After DNS propagation and certificate setup, enable **Enforce HTTPS** in Settings → Pages.

Official guide:
https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site
